GitHub 选型与深度优化

筛选了 5 个项目、3 类 Agent 和 3 组 Skills。逐项查看官方仓库、真实定义、许可与维护记录，再围绕这套十本书、约 186 万字的离线手册决定如何采用。

项目适配评分是本轮判断，不是官方评级或通用质量榜。需求契合35、工程证据20、采用成本20、维护状态15、许可清晰10；低采用成本得高分，Stars不计分。 仓库近期有提交不等于某个技能文件刚更新；具体文件证据在各项详情中。未运行上游项目全套测试，不将其宣传语当成本项目实测。

这轮具体改了什么

  • 查十本书：可切换本书与全库检索；结果带书名、章节和命中片段，跨书跳转后仍可回到结果。
  • 让大部头搜索更轻：缓存用于匹配的文字，只给当前可见部分绘制高亮，保留全书静态正文。中文输入法组词时不提前检索。
  • 让记录能带走：JSON 完整备份与预览恢复，合并新心得和探索标记，保留本机已有心得与位置；原 Markdown 导出保留。
  • 键盘直接读：全书页增加跳过目录入口，搜索跳到命中句子并交付焦点，手机主要控件至少 44px。

实际运行：已有 Playwright 浏览器测试与本地 axe-core 4.10.3；沿用本机 Impeccable、TDD 和完成前验证技能。外部 Agent 作为已审阅的流程参考，未安装为常驻 Agent；MiniSearch、Pagefind、Readest、foliate-js 均未作为成品运行依赖引入。

继续优化：书签、配色与续读

  • 书签记录原文词句位置；换字号与跨阅读布局后仍可定位。同节更新、最多500枚、删除可撤销；满额和已有新书签时给出准确反馈。
  • 纸色、夜读、素白可选，默认保持纸色；切色保留阅读位置，配色随完整备份带走。
  • 主手册完整备份包含书签，全书页另有书签导出，可解决直接双击HTML时各文件记录分离的问题。浏览器禁止保存时仍可导出临时书签。
  • 书签按书籍、章节名和摘录词句筛选，每批显示40枚。删除撤销保持筛选，导出仍包含完整书签集合。
  • 多页面暂存合并超过500枚时，不把截断列表写回磁盘；完整导出保留合并集合，导入预览明确未合并数量。
  • 从跨书书签进入后继续阅读，刷新和返回保留最新位置；新打开原书签链接仍回原句。
  • 修复末尾短章节的目录误判、浏览器返回时的续读偏移和键盘切换工具栏时正文被意外滚动的问题；新打开的明确章节链接保持优先。

书签、配色、边界与转移共 77 项专项检查通过；既有搜索、心得、备份与全书阅读回归也通过。十书 2,859 节、1,862,865 字符与转换数据逐节一致，原文件及原页图仍完整。主手册与全书页面在 320px 和桌面布局检查通过；四种书签筛选状态的 axe 扫描无明确自动违规，部分项目仍需人工判断。
