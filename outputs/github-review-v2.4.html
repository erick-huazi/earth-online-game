这轮解决了什么问题

朋友收到远征后可以逐站回看当时的取舍，也可以另开一局挑战。二维码支持这两种用途。阅读时搜索到某一章，还能在原句之间逐处移动。

新增的玩家端库是二维码生成器。回放压缩复用已有 lz-string 1.5.0；查找沿用上一版的中文归一化与原文位置映射。解码库和浏览器测试工具在开发侧使用。

上游 Agent 与 Skill 的方法已整理为项目技能 .agents/skills/earth-online-playtest/SKILL.md。修改回放或阅读定位后，用它规划场景、运行相关验收，再补测一条相邻路径。

八个候选的评分与取舍

沿用上轮权重，需求适配占 30 分，离线可用占 20 分，维护与稳定占 15 分，许可适配占 15 分，运行负载与接入成本各占 10 分。负载和接入得分越高，表示对玩家设备和项目维护者的负担越小。按各项在本项目中的实际用途评分。

怎样复核

  1. 完成远征后打开分享窗口，分别生成挑战和回放二维码。解码后核对原链接，挑战应打开相同开局，回放应打开已完成远征的行程。
  2. 另开一个浏览器环境，开始一局并记下当前站。打开朋友的回放，浏览第二站和最后一站后关闭。重新打开自己的远征，核对开局、当前站与资源。再试一份被截断的回放口令。
  3. 离线打开《道德经》单书页，搜索“道”，逐处前进、后退，观察当前命中与总数。手册里进入第一章搜索同一个词，比较章内的计数和正在高亮的字。

在本版成品中的实测

  • 在两个相互隔离的 Chrome 会话中，从真实结算导出 12 站远征。观众按 End 跳到最后一站，按 Home 回到首站，再按 Esc 并重载，原有进行中存档逐字一致。截断口令后再次验证了已有存档。
  • 在 320 像素断网视口打开《道德经》全书，搜索“道”得到 37 节、76 处。按 Enter 到下一处，再按 Shift+Enter 返回，上下文相同且焦点仍在搜索框。手册同书第一章共有 3 处，从第 1 处向前抵达第 3 处，向后再次回到第 1 处。
  • 在 file:// 成品中打开分享窗口，独立解码器从导出 PNG 和画面上的二维码还原出相应的回放、挑战链接。源码仓库的 npm run test:sharing 和 npm run test:occurrence 可分别复跑分享与定位用例。
