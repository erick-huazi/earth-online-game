按原 PDF 页序，直达想读的位置

原来的问题
《毛选》和《炁体源流》卷册长，只能翻阅读节时，不容易从原 PDF 页码找到对应文字。
现在的变化
增加卷册与原文件页码定位。毛选第三卷原文件第 151–153 页属于同一修复阅读节，输入其中任一页都能到达该节；越界或非整数输入会给出可纠正的提示。
如何使用
打开《毛选》或《炁体源流》的阅读工具，选卷册、填原文件页码，再确认跳转。这里使用 PDF 文件页序，不是纸书印刷页码。

本项专项检查：5 项通过

02已落实

查看书首工具后，回到刚才阅读处

原来的问题
在独立全书页查看配色、目录或书签时，页面滚回书首可能被当成新的阅读位置。
现在的变化
保留刚才正文中的位置，并提供返回入口。查看书首工具和筛选书签不再覆盖正文续读；明确选择新章节时，以新的阅读目标为准。
如何使用
在全书页回到书首设置工具，再使用“返回刚才阅读处”。中途刷新也会恢复已保存的正文位置。

本项专项检查：10 项通过

03已落实

多窗口写心得，保留另一边的记录

原来的问题
两个手册窗口各自持有旧存档时，后来保存的一边可能覆盖另一边刚写下的心得或探索标记。
现在的变化
在已测多窗口场景中合并不同书的记录；同一本书出现不同心得时，保留可读的分歧副本。完整 JSON 备份和 Markdown 导出都携带这些副本。
如何使用
照常记录心得和探索标记；出现另一份心得时可阅读副本，再决定如何整理。换设备或清理浏览器前，下载完整备份。

本项专项检查：14 项通过

04已落实

键盘打开一本书后，继续在书里阅读

原来的问题
从星图或阅读路线按 Enter 打开书后，焦点曾留在原按钮；再按 Tab，页面会滚回原导航区域。
现在的变化
打开书时把键盘焦点交给阅读区域，下一次 Tab 继续访问阅读控件。星图、阅读切换、阅读主题和原文区四处命名区域补齐语义角色。
如何使用
用 Tab 选中星图节点或阅读路线，按 Enter 打开，再按 Tab 继续。原文和导读模式都纳入本轮检查。

本项专项检查：6 项通过

05已落实

简体、繁体和省略标点，都能查找

原来的问题
“北冥有鱼”“逍遥游”匹配不到繁体原文；“道可道非常道”少了标点，也会没有结果。
现在的变化
主手册、本库十书和独立全书共用兼容检索，默认忽略简繁字形差异、标点与空白。高亮仍保留原来的文字、标点和换行；需要逐字查询时可选精确匹配。首次索引分批准备，输入法与过期查询保护保留。
如何使用
在搜索框直接输入词句。主手册在“目录与搜索”内、独立全书在书首工具末尾切换“查找方式”。检索不依赖网络。

本项专项检查：14 项通过

06已落实

心得副本可以复制，也可以接着整理

原来的问题
多窗口产生的不同稿件虽然已保留，但只能查看，重新整理需要手工搬运。
现在的变化
每份副本增加复制和继续整理入口。开始整理前保存原心得、本页草稿和选中副本，后续编辑不会改写这些保留稿。无法先保存原稿或副本已更新时，不直接替换编辑框；原稿已保存但新稿暂未保存时，会明确提示另行导出。
如何使用
在“导读与心得”展开副本，点“复制这份心得”或“作为当前心得继续整理”。浏览器不允许自动复制时，正文会被选中并给出手动复制提示。
