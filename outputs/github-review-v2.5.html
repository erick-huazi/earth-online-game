两项改动

战报里的每一站都可以重走。选一条不同路线，看它把资源和结局带向何处，然后返回朋友的原战报。读书时，选中某一句就能保存摘录，在手册和独立全书之间回到同一段。

本版增加一个开发依赖 fast-check，玩家打开离线 HTML 的运行环境保持原样。两项交互由本项目实现，测试方法已纳入仓库里的 earth-online-playtest 技能。

五个候选如何评分

每项按本项目需求独立判断。需求适配占 30 分，离线可用占 20 分，维护与稳定、许可适配各占 15 分，运行负载、接入成本各占 10 分。后两项满分表示对玩家设备和项目维护者的负担最小。每个来源都链接到核查时的固定提交。

fast-check

97 分

测试依赖 · 已接入

同一个存档可以走许多条路线，逐条手写测试很难覆盖。本项目让生成器选择种子、角色、站点和替代行动，把分岔时的资源与正向游玩时记录的状态逐项核对。两个文本用例组另行生成罕用字、组合字符、重复句和移动过的原段。缩减后的反例可用种子与路径重跑。

怎样复核

  1. 在旧版生成一份完整远征战报，另开浏览器会话存一局进行中的远征。在新版本打开旧战报的末站，改走另一条路线直至出现两种结局。返回末站并刷新，核对自己的原存档。
  2. 在《道德经》第一章同时保留章节书签和一段摘录。从手册的书签面板打开“全书中读”，核对选中的词句、章次和在原文中的起点，然后刷新。
  3. 在仓库根运行 npm run test:properties，三个用例组每组各生成 128 组输入。npm run test:practice 与 npm run test:clippings 可分别重跑游戏与阅读器的浏览器验收。

独立实测

360 像素宽的 Chrome 会话在同一网址从 v2.4.0 切换到新版。从旧战报第 12 站换路线直到结局，再返回原站。练习中、关闭后和刷新后取得的正式存档均与原字节一致。

同一会话保留旧章节书签，只摘取《道德经》第一章的第二个“道”。在新标签的全书与刷新后的页面中仍选中这个字，章次、起点与手册一致。评分页通过 320 和 1280 像素宽度检查。
