地球 Online v2.10 · GitHub 项目与技能评估 · 2026 年 11 月 27 日

在两台设备答过同一天的题，怎么接着玩？

在原设备下载存档，把文件带到另一台设备。导入前可以先查看有哪些答题与复习记录可以合并。接收设备已经留下的首次答案会保留，相同进度可以重复导入。

四个候选的适配评分

按本轮采用方式评分。需求适配占 30 分、离线可用占 20 分，维护与稳定、许可适配各占 15 分，运行负载、接入成本各占 10 分。后两项越高，接入给游戏带来的额外负担越小。四个候选均未增加玩家端的运行时依赖。

Dexie export-import

97 分

采用版本校验和导入预览

Dexie 导出文件带有格式名、版本和各表的条目数。导入模块可以先读取文件概要，也会检查格式与支持的版本。它原生处理 IndexedDB 数据库。

辨典存档使用自己的 JSON 格式，读取后先展示本机将加入的进度与冲突。只有玩家确认才写入。本版继续使用游戏已有的浏览器存储。

Git 快进合并

95 分

借鉴同一段历史可以续接的条件

Git 遇到当前提交是另一提交祖先的情况，可以把分支直接前移。出现分叉后，单靠这一步无法判定应当采用哪条历史。

游戏将这个判断用于同一天的首答。两边已经答过的题逐题一致时，可以保留较长的相容进度。若同一题的首次选择不同，预览会指出冲突，保留接收设备的日卷。游戏用本地 JavaScript 比较答案。

Property-Based Testing

93 分

采用 Agent 技能的测试方法

这份技能列出了适合生成输入验证的性质。序列化适合做往返检查，对会重复执行的操作可检查幂等性。

将这些性质用于辨典备份。由存档导出再导入后，答题和复习进度应能还原；对同一台设备连续导入同一个文件，第二次的记录应与第一次一致。验收沿用项目中的测试工具。

Automerge

77 分

多人协作场景备选

Automerge 能合并多个副本中的变更，并提供读取同一属性并发取值的接口。它的 JavaScript 实现使用编译为 WebAssembly 的核心。

两台设备对同一道题作出不同首答时，游戏需要给玩家解释保留哪份记录。手动导入已有明确的合并规则，引入完整的协作文档、变更历史和运行时会增加离线包与旧档迁移成本。本轮保留为未来协作编辑的备选。
